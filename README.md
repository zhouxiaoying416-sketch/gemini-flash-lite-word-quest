# English Word Quest

A standalone ten-question English vocabulary game with Chinese explanations, scoring and mistake review.

Open index.html locally, or use the GitHub Pages site when its build completes. No API key or network request is needed while playing.

Created on 2026-11-02. The initial page was generated through Crazyrouter API using gemini-2.5-flash-lite from a predefined question bank. Local corrections added review explanations, clearer feedback, state guards and narrow-screen styling. Eleven virtual DOM behavior tests pass; real-browser visual verification is still pending.
